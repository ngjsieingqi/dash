# Dashboard

A dark, minimal habit + to-do dashboard. Clock & greeting, habit streaks, to-do list, countdowns, and quick links. All data saves in your browser (localStorage) — no account, no server.

## Deploy to GitHub Pages (works on a locked Chromebook, browser only)

1. Go to **github.com** → **New repository**. Name it anything (e.g. `dashboard`). Make it **Public**. Click **Create**.
2. On the new repo page press the **`.`** (period) key — this opens **github.dev**, a VS Code editor in your browser tab.
3. Create a file named **`index.html`**, paste in the contents of `index.html`, and do the same for this `README.md`.
4. Open the Source Control panel (left sidebar), write a message, **Commit & Push**.
5. Back on the repo: **Settings → Pages → Source: Deploy from a branch → `main` / `root` → Save.**
6. Wait ~1 minute. Your site is live at `https://YOUR-USERNAME.github.io/dashboard/`.

## Make it your homepage
Chrome/Chromebook: **Settings → On startup → Open a specific page** → paste your Pages URL. (If the policy is locked, just bookmark it.)

## Notes
- Data is per-browser. Clearing site data wipes it.
- Default quick links (Classroom, Drive, Gmail, GitHub) are editable — hover a link and click ✕ to remove, or use **+** to add your own.
- Click your name in the greeting to change it.
